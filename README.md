# Team Task Manager

A full stack Team Task Manager web application built using React.js, Node.js, Express.js and MySQL.

---

## Features

- User Signup & Login
- Dashboard
- Create Projects
- Create Tasks
- Delete Tasks
- Profile Page
- Logout Feature
- Modern Responsive UI

---

## Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- Sequelize ORM
- MySQL

---

## Installation

### Backend Setup

cd server

npm install

npm start

---

### Frontend Setup

cd client

npm install

npm run dev
