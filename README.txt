Team Task Manager
A full stack Team Task Manager web application built using React.js, Node.js, Express.js and MySQL.
Frontend live:  https://team-task-manager-git-main-hitendra-kumar-s-projects.vercel.app/


Backend live:  team-task-manager-production-6f19.up.railway.app


Features
User Signup & Login
Dashboard
Create Projects
Create Tasks
Delete Tasks
Profile Page
Logout Feature
Modern Responsive UI
Tech Stack
Frontend
React.js
Axios
React Router DOM
Backend
Node.js
Express.js
Sequelize ORM
MySQL
Installation
Backend Setup
cd server

npm install

npm start

Frontend Setup
cd client

npm install

npm run dev
